## 安装提示

- Android 10（API 29）及以上，需与音箱处于同一 Wi-Fi。
- 正式包使用固定签名证书；若系统提示“未知来源”，请允许当前浏览器/文件管理器安装应用。
- 免费版同时最多 2 台音箱；Plus 解除数量限制。

> 本应用与小米公司无官方关联，MiPlay 为小米的协议名称。
